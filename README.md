# 🔐 CryptoVis — Visual Cryptography Playground

CryptoVis is an interactive web application built to help students and beginners understand
classical cryptography algorithms through real-time visualization.

It visually demonstrates how plaintext transforms into ciphertext using well-known ciphers.

---

## 🌐 Live Demo
👉 https://cryptovis-nine.vercel.app/

---

## 🧠 Features

- 🔄 Real-time encryption visualization
- 🔐 Caesar Cipher implementation
- 🔑 Vigenère Cipher implementation
- 🎓 Beginner-friendly UI
- ⚡ Lightweight and fast
- 🧩 Open-source project
